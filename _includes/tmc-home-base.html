TriMicroCluster

An evolving instrument for autonomous composition.

TriMicroCluster is an experimental generative musical instrument developed for the monome norns environment. It explores microtonality, evolving musical relationships and the autonomous organisation of musical time.

Autonomous organisation of musical time. The Conductor shapes participation, withdrawal and change across different timescales. It establishes conditions within which individual layers can develop their own behaviours.

Personal account · To be expanded

From conversation to composition

For decades, conventional writing and documentation made complex musical ideas difficult to develop and sustain. A conversational workflow made it possible to work in a way that feels more natural — speaking ideas, testing them, revising, and retaining a shared record.

The full creative trail

Rather than presenting only polished results, this archive will show original intentions, implementation decisions, listening notes, discarded designs and lessons learned. The human artist guides musical outcomes; AI supports exploration and implementation.

Two editions · Different contexts

Core & Advanced.

A standalone public instrument and a specialised personal performance system. Both can be documented, but only Core is intended for public software distribution.

Public release planned

Core

The edition intended for the norns community. Compatibility work, testing and documentation are required before an open-source release. It will not depend on the artist's specialised Advanced hardware setup.

Documentation only

Advanced

An expanded environment integrating additional MIDI, percussion, external hardware and personal performance practices. Its design, research and musical results can be documented, but its specialised source code will not be offered for public download.

There are currently no public downloads on this website. Core compatibility and release readiness will be confirmed through testing.
Architectural notes

Organising musical time.

Temporal simply means relating to time. In TriMicroCluster, this encompasses participation, duration, changing density and relationships between musical events. The Conductor coordinates conditions rather than prescribing every note. Some layers, including SubHarm, retain established exceptions to PLAY/IDLE permission gating.
