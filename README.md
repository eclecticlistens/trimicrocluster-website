# TriMicroCluster — website and living archive

Public website repository for TriMicroCluster, an evolving instrument for autonomous composition.

**Website:** https://eclecticlistens.github.io/trimicrocluster-website/

## Reading the documentation

- [Instrument](instrument.html): musical purpose and the October 2026 eight-layer Advanced snapshot
- [Architecture](architecture.html): the Conductor, temporal organisation, and Anchor / Orbit / Shimmer
- [Dyslexia, AI & Creative Process](process.html): first-person draft, development method and documented before/after case
- [Core & Advanced](editions.html): separate public software policy and private specialised system
- [Development Journal](journal.html): dated decisions and differences between coding, listening and hardware evidence
- [Research & Resources](research.html): discussed books, verified technical references and proposed reading
- [Listen](listen.html): how audio and audiovisual evidence will be documented when approved

Each documentation page includes an optional **Reading layout** control for larger text and more spacing. Text remains selectable; diagrams have descriptions.

## Evidence and editorial policy

- **Recorded:** a decision or listening outcome explicitly present in development discussions.
- **Proposed:** a design idea, reading or planned activity; not proof of implementation.
- **To verify:** a claim requiring a current code inspection, an original document or hardware test.

The currently published articles are editorial drafts based on documented discussions and research, not comprehensive verbatim transcripts. Historical statements can be corrected as the artist reviews his archive.

The 'AI and Dyslexia' account is explicitly a **first-person draft for approval**, not an authenticated quotation from one source conversation.

## Software distribution

This is a **website and documentation repository**, not a public TriMicroCluster instrument release.

- **Core:** intended for later open release after compatibility and licence work.
- **Advanced:** artist-specific system; documented but not offered for public source download.

No TMC Advanced code, private backup or unapproved sample libraries are stored in this repository.

## Visuals

The aluminium and warm orange palette is an artistic identity derived from discussions of norns and grid hardware. Monome grids vary by edition. The homepage uses the approved photographic-style Grid rendering stored in `assets/images/grid-photo.webp`. It is an illustrative visual, not a verified map of the installed instrument's controls or LED states; see [Grid & Visual Feedback](grid.html) for that distinction.

## Maintenance

Website pages are simple HTML and use a shared `docs.css`; there is no build step. GitHub Pages can publish directly from the repository's `main` branch, root folder. New text should preserve factual status labels, accessible reading structure and source links.
